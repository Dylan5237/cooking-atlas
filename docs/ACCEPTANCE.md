# MVP 验收
- [ ] owner 创建家庭空间并邀请成员
- [ ] 成员只能访问所属空间数据
- [ ] 只有 owner 可增删改菜谱
- [ ] 图片/语音/文字 AI 录入并由 owner 确认
- [ ] 真实照片生成卡牌
- [ ] 成员收藏、提交点菜和备注
- [ ] AI 优先从已有菜谱推荐，新菜明确标记
- [ ] 过敏原和禁忌为硬约束
- [ ] owner 汇总、调整、确认菜单
- [ ] 仅已确认菜单可生成采购清单
- [ ] 同名同单位食材合并并追踪来源
- [ ] 未知用量不伪造精确数量
- [ ] 支持家中已有/已购买状态
- [ ] 菜谱修改不污染历史菜单快照
- [ ] 完成烹饪记录与照片保存
- [ ] 真机走通家庭晚餐闭环
