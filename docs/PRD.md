# 我的料理图鉴 · MVP 产品规格

## 已冻结决策
- 首发微信小程序，未来公开发布。
- 首期自己和家人共同使用。
- 家庭空间是菜谱、菜单和采购数据的归属边界。
- 只有 owner 能录入、编辑、删除菜谱；成员可浏览、收藏、点菜。
- 全体成员提交点菜，系统汇总后由 owner 确认正式菜单。
- AI 优先推荐已有菜谱；不足时可推荐新菜，但必须标记为新菜建议。
- 采购清单仅从已确认菜单生成。
- 采购数量根据菜谱快照与人数计算；未知用量不伪造精确数值。

## 闭环
AI 录入 → 卡牌收藏 → 家人点菜 → AI 配餐 → owner 确认菜单 → 采购清单 → 采购 → 烹饪记录。

## 页面
图鉴（卡牌墙、分类、搜索、菜谱详情、owner 录入）；点菜（人数、场景、家人提交、AI 推荐、菜单确认）；采购（食材汇总、数量调整、家中已有/已购买）；我的（家庭空间、成员、偏好）。

## 权限
| 操作 | Owner | Member |
|---|---|---|
| 浏览菜谱 | ✓ | ✓ |
| 菜谱增删改 | ✓ | — |
| 收藏/点菜 | ✓ | ✓ |
| 确认菜单 | ✓ | — |
| 生成采购清单 | ✓ | — |

## 非目标
公开社区、商城、支付、完整库存、会员体系、复杂游戏化不进入 MVP。
