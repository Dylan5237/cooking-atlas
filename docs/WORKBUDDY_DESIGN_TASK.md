## 2. 本次要完成

复用 `apps/miniprogram` 与共享业务引擎，完成微信登录/会话、选图与上传、录音、完整菜谱 Canvas 导出到相册、分享、导航与安全区，以及真机兼容。后端继续使用 **Node.js + PostgreSQL + S3 兼容对象存储**。

迁移时保持这些已经验收的行为：

- 主食可明确选择、自动搭配或本餐不安排；相同菜谱不重复计量。删除某项后，首次推荐和换组都排除它；主动重新加入后恢复资格。删除米饭只排除米饭这道菜，整餐不吃主食使用“本餐不安排”。
- 按每道菜的原配方份数和计划份数生成菜单快照、采购用量；未知份数要求补充，未知用量如实显示。
